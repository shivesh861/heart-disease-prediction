# ❤️ Heart Disease Prediction

A Machine Learning web application that predicts the risk of heart disease based on user-provided health parameters.

## 🚀 Live Demo

[Open the deployed app](https://heart-disease-prediction-fxawh3neicw438seam5qwr.streamlit.app/)

## 🛠️ Technologies Used

- Python
- Scikit-learn
- KNN (K-Nearest Neighbors)
- Pandas
- Joblib
- Streamlit

## 📌 Features

- Interactive user input
- Heart disease risk prediction
- Trained KNN machine learning model
- Data preprocessing using StandardScaler
- Web interface built with Streamlit

## 📊 Input Parameters

The application takes:

- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol
- Fasting Blood Sugar
- Resting ECG
- Maximum Heart Rate
- Exercise-Induced Angina
- Oldpeak
- ST Slope

## ⚙️ Run Locally

Clone the repository:

```bash
git clone https://github.com/shivesh861/heart-disease-prediction.git
cd heart-disease-prediction
Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
